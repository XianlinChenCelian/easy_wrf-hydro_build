离线建模 / 空间输入

流域制备

从已有 WPS 网格与高程数据生成水文路由网格、参数文件和离线初始场。

空间输入

地形栅格应覆盖整个 WPS 网格。

支持等间距 Lambert 网格。
CSV 字段为 FID、LAT、LON。

水文网格与汇流

设置陆面到水文网格的细化倍数，以及起河所需的累计网格数。

读取 WPS 网格后显示水文间距。
阈值越大，提取的河网通常越稀。
同目录保留同名 .shx、.dbf 和 .prj。

版本与输出

参数表须对应模型版本和地类。工具按网格中的 MMINLU 选择 USGS 或 MODIS 表。

可直接修改完整路径。输出目录应尚未存在。

结果包含 DOMAIN、路由 ZIP 和各阶段日志。
