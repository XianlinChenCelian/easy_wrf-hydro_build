# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not include passwords, license files, private source archives, host names, or
other sensitive environment data in a public issue. Use GitHub private
vulnerability reporting when it is enabled for the repository. Otherwise,
contact the repository owner privately before disclosing details.

Build logs attached to issues should be reviewed and redacted first. In
particular, remove user names, absolute private paths, proxy credentials, and
Intel license information.
